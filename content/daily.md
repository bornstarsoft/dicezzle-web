Daily Dice is coming soon. The Classic game ships first so the core board, merge rules, scoring, and sharing feel good before daily seeds are added.

When Daily Dice arrives, it will use deterministic tray seeds and local progress keys such as `dicezzle.dailyCompleted.YYYY-MM-DD`.
